# 考研背诵系统 v1.0

一个基于 Web 的智能背诵复习工具，采用艾宾浩斯遗忘曲线算法，帮助高效记忆考研知识点。

## 功能特性

### 四大核心模块

- **仪表板** — 今日待复习、昨日完成、总内容数、已掌握数量、学习进度、Box 分布统计、快速操作入口
- **复习** — 翻转卡片动画，支持「遗忘 / 模糊 / 熟练」三级评价，显示复习次数、上次复习时间、当前 Box 等级
- **学习日历** — 月历视图展示每日任务状态（待复习 / 已完成 / 今日任务），支持打卡、日期导航
- **内容管理** — 创建 / 编辑 / 删除、搜索、按类型筛选（闪卡 / 段落）、查看详情

### 两种内容模式

| 模式 | 说明 |
|------|------|
| 闪卡 | 问题-答案配对，适合名词解释、公式、概念 |
| 段落 | 纯文本，适合论述题、长段落背诵 |

### 智能复习调度

基于艾宾浩斯遗忘曲线，将内容分为 5 个 Box 等级：

| Box | 复习间隔 | 说明 |
|-----|---------|------|
| 1 | 1 天 | 新内容 / 刚遗忘 |
| 2 | 2 天 | 初步记忆 |
| 3 | 4 天 | 加深记忆 |
| 4 | 7 天 | 基本掌握 |
| 5 | 15 天 | 已掌握 |

复习时选择「遗忘」回到 Box 1，选择「熟练」晋升一级。

### 数据导入导出

- 手动输入添加
- TXT / CSV 文件导入（支持拖拽上传）
- JSON 备份导出 / 恢复
- config.json 配置文件自动同步

### 键盘快捷键

| 按键 | 功能 |
|------|------|
| `Space` | 翻转卡片 |
| `1` | 标记遗忘 |
| `2` | 标记模糊 |
| `3` | 标记熟练 |

## 快速开始

### 环境要求

- Python 3.x
- 现代浏览器（Chrome / Firefox / Edge）

### 启动方式

**方式一：一键启动（推荐）**

双击桌面的 `启动背诵系统.sh`，自动完成服务器启动和浏览器打开。

**方式二：手动启动**

```bash
cd /path/to/Recite_System
python3 server.py
```

然后浏览器访问 `http://localhost:8000`

> 使用 `server.py` 启动时，网页端的数据修改会自动同步写入 `config.json` 文件。
> 如果使用 `python3 -m http.server`，数据仅保存在浏览器本地，需手动导出备份。

## 项目结构

```
Recite_System/
├── index.html       # 主程序（单文件，HTML + CSS + JS）
├── config.json      # 数据配置文件（自动读写）
├── server.py        # Python 后端服务器
└── README.md        # 项目说明
```

## 技术架构

- **前端**：单文件 HTML，原生 JavaScript，无第三方依赖
- **后端**：Python `http.server`，提供静态文件服务和 `/api/save` 写入接口
- **存储**：`config.json` 文件持久化 + 浏览器 localStorage 双重备份
- **同步策略**：页面加载时自动比较 `config.json` 与 localStorage 的时间戳，取最新数据合并

## 界面预览

深色主题设计，紫色 + 青绿配色，支持渐变、毛玻璃效果和动画过渡，响应式适配手机 / 平板 / 桌面端。
